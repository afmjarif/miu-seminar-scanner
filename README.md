# MIU Seminar Scanner

A QR code-based participant verification and attendance tracking system developed for the **MIU CSE Club ICT-Based Seminar 2026**.

## Features

- QR code scanning
- Participant verification
- Registration ID verification
- Entry tracking
- Food tracking
- Duplicate entry detection
- Google Sheets integration
- Google Apps Script backend
- GitHub Pages deployment

## Event

**ICT-Based Seminar 2026**  
**Theme:** Beyond the Classroom: AI, Careers & Digital Security  
**Organized by:** MIU CSE Club  
**Venue:** Auditorium, MIU  
**Date:** 09 August 2026
